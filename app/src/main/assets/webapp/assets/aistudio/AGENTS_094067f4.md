- CAMIQ is one app with three role areas (/student, /guard, /admin) under `_authenticated`; roles live in `user_roles` and RLS enforces access — UI gating in AppShell is cosmetic only.
- Cameras are browser webcams (getUserMedia); the physical device is assigned per computer in localStorage, while camera metadata/heartbeat lives in the `cameras` table. Why: the app runs on the web, not a local Python service.
- Gate QR validation and token issuing run in SECURITY DEFINER SQL functions (`issue_pass_token`, `consume_gate_token`) so consumption is atomic with anti-passback.
- Camera selection logic lives in `src/lib/geo.ts` (`planCameras`) and is shared by student, guard and admin screens; keep it pure and tested.
- tsconfig drops exactOptionalPropertyTypes/noUncheckedIndexedAccess/noPropertyAccessFromIndexSignature/noImplicitReturns to keep form-heavy code readable; `strict` stays on.
